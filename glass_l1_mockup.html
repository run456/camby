液态玻璃 L1 设计稿 · 可视化对比

左：现状 霜态（Frost） —— 仅高斯模糊 + 灰白 tint，色彩发闷、边缘无厚度。
右：L1 凝态（Frozen） —— 模糊 + 色彩矩阵(saturate 1.6 / contrast 1.1) + 内发光 + 亮边，背景色块被「冻住」、边缘有厚度。
同一张彩色背景之上，对比色彩鲜活度与边缘厚度差异。
现状 · 霜态 FROST
影片详情
模糊 + 灰白 tint（0.10）稀释背景 → 发闷发灰；1px 细边无厚度；静态对角高光偏弱。
L1 · 凝态 FROZEN
影片详情
backdrop-filter: blur(22px) saturate(1.6) contrast(1.1) + 内发光 inset 0 0 24px + 亮边 .22/0.9px + 高光提档 → 颜色鲜活、边缘有厚度。
色彩透传
● 凝态：saturate 1.5–1.8 + contrast 1.1，颜色「冻」在玻璃里。
● 霜态：低饱和 + 灰白 tint，发闷发灰。
边缘光学 / 体积
● 凝态：内发光 + 亮边 + 外阴影 = 两层厚度感。
● 霜态：平切边、一层平面，背景与卡片两张皮。
性能 / 改动
● 凝态：色彩矩阵走 CPU(ColorFiltered)，GPU 采样不增；仅改 Glass.build 一处，可独立回滚。
● 霜态：1 次模糊采样。
说明：本页用浏览器 backdrop-filter 近似还原（色彩矩阵以 saturate/contrast 叠加、内发光以 inset 阴影近似），用于方案评审； 真机实现以 GLASS_L1_DESIGN.md 的 ColorFiltered + 内渐变/自定义 painter 配方为准。L2 液态（真折射 shader）不在本次范围。
