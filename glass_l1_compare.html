同一套 Glass 组件改造后，弹窗、底部抽屉、导航条、图标按钮会整体从霜态跳到凝态。下方每组左为现状、右为 L1。

弹窗 / 详情卡（现状·霜态）

模糊 blur(22px) 仅此一项
tint white .10 灰白稀释
边 white .18 / 1px 平切、无厚度
高光 静态对角 .26，偏弱

弹窗 / 详情卡（L1·凝态）

tint white .06 让位色彩矩阵
边 white .22 / 0.9px 亮边
厚度 内发光 inset 0 0 24px + 外阴影

背景 半透白 .10 + 细边 .18，压在彩色页上时发闷、无浮起感。

底部导航条（L1·凝态）

首页搜索我的
背景 半透白 .06 + 饱和度/对比 + 内发光 + 亮边，彩色页透出更鲜活、条体更「实」。
色彩透传
凝态：saturate 1.5–1.8 + contrast 1.1，颜色「冻」在玻璃里；霜态：低饱和 + 灰白 tint，发闷发灰。
边缘光学 / 体积
凝态：内发光 + 亮边 + 外阴影 = 两层厚度感；霜态：平切边、一层平面，两张皮。
性能 / 改动
凝态：色彩矩阵走 CPU(ColorFiltered)，GPU 采样不增；仅改 Glass.build 一处，可独立回滚。
说明：本页用浏览器 backdrop-filter 近似还原（色彩矩阵以 saturate/contrast 叠加、内发光以 inset 阴影近似），用于方案评审； 真机实现以 GLASS_L1_DESIGN.md 的 ColorFiltered + 内渐变/自定义 painter 配方为准。L2 液态（真折射 shader）不在本次范围。
